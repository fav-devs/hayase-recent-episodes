# Design

The plugin is embedded in Hayase's existing Home UI. Inherit its sans-serif typography, foreground and background theme tokens, and restrained borders. Follow the host's compact section headings, horizontal content rows, muted secondary text, and ordinary buttons. Support both light and dark host themes instead of assigning an independent theme. Use no decorative animation or generated artwork. Release items show title, episode, version and local release time; controls remain usable by keyboard with visible focus.
