# Native Hayase preview

The plugin compiles Hayase's actual `preview.svelte`, image/banner loaders, YouTube preview, buttons and animated icons. See `upstream.json` for the pinned repository commit and unchanged-file hashes. The Play button has one deliberate source change: its conditional label is replaced with the user's requested **Play now**.

Adapters supply the public anime metadata, local/public account state, settings and native action handoff. They do not replace the preview's markup, CSS, button variants, trailer code or information layout. The generated bundle runs inside a nested shadow root to isolate native utilities from the surrounding plugin card. A fixed-position portal keeps it visible outside the scrolling row, with viewport-edge clamping.

`utilities.css` is a checked-in Tailwind 3 snapshot generated from these component classes using `scripts/native-tailwind.cjs` and `theme.css`. It preserves Hayase's relative theme colors and custom `select` variants. The build does not regenerate this snapshot with the installed Tailwind 4 peer dependency. Update the snapshot deliberately when changing the pinned upstream classes.

Banner lookup uses Hayase's `hayase.ani.zip/v2/images/tmdb` endpoint through the extension worker and retains the native fallback to AniList/trailer/cover images. The endpoint can reject this environment with Cloudflare; the fallback remains usable. Favorites, bookmark state and spoiler hiding use local history and public linked-list data. Private state unavailable to the plugin remains a limitation; action clicks go to Hayase's real native controls.

The public `hayase.app` UI returns a 401 in the development browser. Native component geometry and controls are tested from the compiled upstream source, but a side-by-side test against the installed desktop app remains required before claiming complete live-app parity.

Upstream-derived files carry Hayase's BUSL-1.1 license, included in `plugin/HAYASE-LICENSE.txt`. Bundled open-source dependencies are documented in `plugin/OSS-LICENSES.txt`, regenerated by the build.
