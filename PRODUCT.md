# Product

## Register

product

## Users

Hayase desktop users choosing which newly available anime episode to watch. The initial user wants subtitled releases and English dubs, browsable by day or week.

## Product Purpose

Add a recent-episodes section to Hayase Home through a desktop Chrome-extension plugin. Success means quickly finding an episode released in the chosen period and opening its existing Hayase anime page. Users can also reorder, hide and restore Home sections, with layout preferences saved locally between app sessions.

## Brand Personality

Familiar, restrained, clear. Follow Hayase's existing home rows and controls, as confirmed by the user.

## Anti-references

Avoid a separate dashboard aesthetic, marketing surfaces, and a visual redesign of the host app. The user explicitly chose to match Hayase's UI.

## Design Principles

- Fit the existing Home workflow.
- Distinguish release versions and episode numbers clearly.
- Never present estimated broadcast times as verified availability.
- Keep failures and incomplete coverage understandable.

## Accessibility & Inclusion

Use semantic controls, keyboard navigation, visible focus states, readable inherited typography, and status announcements. No additional accommodations were requested.
